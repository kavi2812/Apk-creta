=========================================================
HYUNDAI CRETA 2024 OEM LAUNCHER (BLAUPUNKT KEY LARGO 980)
=========================================================

OPTION A: BUILD DIRECTLY ON PC (ANDROID STUDIO)
1. Extract this ZIP folder.
2. Open Android Studio -> File -> Open -> select the extracted "CretaOEMLauncher" folder.
3. Wait 1-2 minutes for Gradle sync to finish.
4. Click Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. Copy "app/build/outputs/apk/debug/app-debug.apk" to your USB drive.

OPTION B: BUILD IN THE CLOUD WITHOUT INSTALLING ANDROID STUDIO (FREE)
1. Create a free GitHub account and create a new repository.
2. Upload all extracted files from this ZIP into that repository.
3. Go to the "Actions" tab -> select "Build Creta OEM Launcher APK" -> click "Run workflow".
4. After ~2 minutes, download the ready-to-install "Creta-2024-OEM-Launcher-APK" ZIP from the Artifacts section!

INSTALLING ON BLAUPUNKT KEY LARGO 980:
1. Copy the .apk file onto a FAT32 USB pen drive.
2. Plug it into the Blaupunkt rear USB port.
3. Open File Manager on the stereo and tap the APK to install.
4. Open Android Settings -> Apps -> Default Apps -> Home App -> select "Creta OEM Launcher".
